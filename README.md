## 📂 Featured Projects (핵심 프로젝트)

### 🀄 [mahjong-hand-simulation](https://github.com)
> **리치 마작 배패 시뮬레이션 프로그램**
- 마작의 첫 패(배패) 흐름과 확률을 계산하고 실험할 수 있는 시뮬레이터입니다.
- **주요 기술**: `TypeScript`를 활용하여 데이터 구조의 안정성을 확보했습니다.

### 🦤 [bobe-chzzk-bot](https://github.com)
> **네이버 치지직(Chzzk) 채팅 및 방송 관리 봇**
- 스트리머와 시청자 간의 원활한 소통을 돕고, 채팅창 관리 및 명령어 자동화를 지원하는 유틸리티입니다.
- **주요 기술**: `JavaScript`, `Node.js`, 치지직 내부 API 생태계 활용.

### 🧰 [Shittim-Chest](https://github.com)
> **블루 아카이브 디스코드 유틸리티 봇 (싯딤의 상자)**
- 디스코드 서버 내에서 서브컬처 게임 ‘블루 아카이브’의 캐릭터 정보, 게임 내 일정 및 주요 편의 기능을 간편하게 명령어 형태로 조회해 주는 유저 친화적 봇입니다.
- **주요 기술**: `JavaScript`, `Discord.js` 인터페이스 라이브러리.
